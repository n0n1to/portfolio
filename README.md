# Portafolio

Bienvenido al repositorio de mi portafolio personal. Este proyecto es una página web sencilla diseñada para presentar mi perfil

## 🚀 Sobre el Proyecto

El objetivo principal de esta web es mostrar mi experiencia, conocimientos técnicos y formas de contacto de manera clara y directa. Cuenta con un diseño estructurado en tarjetas (cards) y un esquema de colores en modo oscuro absoluto para evitar la fatiga visual.

### ¿Qué contiene la página?
- **Sobre mí:** Breve introducción personal sobre mi
- **Conocimientos y Tecnologías:** Listado visual de las herramientas y lenguajes que manejo (incluyendo etiquetas de estado, como Rust "En progreso").
- **Experiencia Profesional/Académica:** Detalles cronológicos sobre mis estudios y trabajos
- **Contacto:** Enlaces directos a mi GitHub, LinkedIn y correo electrónico, maquetados como botones interactivos.

## 🛠️ Tecnologías Integradas

El proyecto está desarrollado utilizando tecnologías web base (Vanilla), sin necesidad de frameworks pesados, lo que lo hace muy ligero:

*   **HTML5:** Encargado de la estructura y semántica de la web.
*   **CSS3:** Utilizado para los estilos visuales. Emplea diseño en Flexbox, esquemas de color oscuros, bordes redondeados y efectos interactivos (hover) en los botones de contacto.
*   **JavaScript:** Añade interactividad en el lado del cliente (Frontend)
